## Дашборд: метрики

Период выбирается кнопками 7/14/30 дней. Карточки:

| Метрика | Как считается |
|---|---|
| **Новых чатов** | Чаты, созданные за период |
| **Решено AI без менеджера** | Доля чатов за период, где ни разу не было сообщения от менеджера и статус не уходил в `waiting_manager` |
| **Средняя реакция менеджера** | От системного сообщения «запросил подключение менеджера» до первого ответа менеджера — усреднено по всем чатам с эскалацией |
| **Ждут менеджера сейчас** | Чаты в статусе `waiting_manager` прямо сейчас (не за период — текущий срез) |
| **Сообщений от клиентов** | За период |
| **Чатов с менеджером** | Сколько уникальных чатов за период получили хотя бы одно сообщение от менеджера |

## График по дням

Столбчатая диаграмма сообщений по дням, с разбивкой по источнику (клиент / AI / менеджер) — виден баланс нагрузки: если столбец «менеджер» стабильно высокий, это сигнал, что AI недорабатывает и стоит расширить [базу знаний](KNOWLEDGE_BASE.md) или [AI контекст](AI_CONTEXT.md).

## Топ слов без AI

Быстрый и бесплатный срез: самые частые слова (от 4 букв, без стоп-слов) в сообщениях клиентов за период. Не требует вызова AI — просто частотный подсчёт, полезно для мгновенной картины «о чём вообще пишут», без ожидания генерации.

## Нагрузка по часам

Гистограмма количества сообщений клиентов по часам суток (UTC) за период — показывает, в какие часы реально нужен дежурный менеджер.

## AI-темы обращений

Кнопка «Обновить темы (AI)» — анализирует сообщения клиентов за последние 7 дней и выделяет 3–7 главных тем с примерной долей в процентах. В отличие от «Топ слов», это осмысленная группировка похожих вопросов, а не частотность отдельных слов — но каждый вызов стоит токенов AI, поэтому результат **кешируется** (виден таймстемп последнего обновления) и не пересчитывается автоматически при каждом заходе на дашборд.

Тот же механизм используется в еженедельном отчёте админам (см. [docs/AUTOMATION.md](AUTOMATION.md)).

## Канбан-доска

Три колонки по статусу чата — «Ожидают менеджера», «AI активен», «Закрыто» — с переключателем периода (сегодня/неделя/месяц, по времени последней активности чата). Каждая карточка показывает:

- Имя/username клиента и Telegram ID
- Краткое описание проблемы — если в диалоге есть AI-сводка (сохранённая при эскалации через «Кратко: ...»), используется она; иначе — текст последнего сообщения
- Время с последней активности

Клик по карточке — прямой переход в чат.

## API для внешних отчётов

Если нужна своя интеграция (например, дашборд в другом инструменте):

- `GET /api/stats/overview?days=N` — все метрики дашборда одним JSON
- `GET /api/stats/topics` — последние закешированные AI-темы (без нового вызова AI)
- `POST /api/stats/topics` — принудительно перегенерировать темы (стоит токенов)
- `GET /api/chats/board?period=today|week|month` — данные канбана

Все эндпоинты требуют авторизации панели (cookie-сессия), как и остальной API.
