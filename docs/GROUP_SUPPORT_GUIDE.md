# Руководство: Telegram топики (режим группы поддержки)

## Обзор
Режим группы позволяет вести поддержку в Telegram супер‑группе с включённым форумом (topics). Для каждого клиента создаётся отдельный топик, где:
- Закрепляется карточка клиента
- Дублируются его сообщения и ответы ИИ
- Сообщения менеджера из топика маршрутизируются клиенту с сохранением типа и медиа
- Тема визуально отражает статус по эмодзи

## Включение и настройка через панель

Всё, что раньше требовало правки `.env`, теперь настраивается в панели: **Настройки → Telegram топики** (`/settings/telegram`).

- **Включить режим группы** — переключатель (соответствует `TELEGRAM_GROUP_MODE`)
- **ID группы поддержки** — числовой ID супер-группы, должен быть отрицательным и начинаться с `-100...` (соответствует `TELEGRAM_SUPPORT_GROUP_ID`)
- **Шаблон названия топика** — по умолчанию `{emoji} {first_name} ({user_id}) {status_label}`; доступные плейсхолдеры: `{emoji}`, `{first_name}`, `{user_id}`, `{status_label}`
- **Эмодзи по ролям** — какое сообщение только что было (клиент/менеджер/AI/по умолчанию)
- **Эмодзи по статусам** — активен/ждёт менеджера/закрыт

Значения из панели имеют приоритет над `.env` — переменные `TELEGRAM_GROUP_MODE`/`TELEGRAM_SUPPORT_GROUP_ID` в `.env` используются только при первом запуске на пустой базе.

### Как получить ID супер-группы

1. Включите режим форума в настройках самой группы в Telegram (Group Settings → Topics)
2. Добавьте бота в группу и выдайте ему права администратора
3. Узнать ID группы можно, например, переслав любое сообщение из неё боту [@userinfobot](https://t.me/userinfobot), либо через `getUpdates` API — ID будет отрицательным числом вида `-1001234567890`

## Поведение и статус‑эмодзи
- 🔴 Клиент отправил новое сообщение (ожидает ответа)
- 🟡 Менеджер ответил (дан ответ)
- 🤖 Бот дал ответ ИИ
- 🟢 После команды `/close` в топике — чат закрыт, тема становится «спокойной»

## Карточка клиента и дублирование
- При первом сообщении клиента в его топике публикуется и закрепляется карточка:
  - `👤 Клиент`, `🆔 ID чата`, `UID пользователя`
- Все последующие сообщения клиента копируются в топик без повторной «шапки» с reply на закреп
- Ответы ИИ также публикуются в топике после вопроса клиента

## Сообщения менеджера
- Если менеджер пишет в топике:
  - Сообщение отправляется клиенту в исходном формате (текст, фото, видео, документ и т.д.), с префиксом «👨‍💼 Менеджер поддержки» (текст и режим показа настраиваются — см. [BOT_SETTINGS.md](BOT_SETTINGS.md#сообщения-менеджера-клиенту))
  - В топике статус меняется на 🟡
- Команда `/close` в топике (без аргументов) — полностью закрывает чат:
  - Статус чата становится «закрыт», клиент получает уведомление о закрытии
  - Завершает сессию менеджера (и сбрасывает закешированный заголовок сессии, если включён режим «Заголовок один раз за сессию»)
  - Тема топика переименовывается под статус 🟢
  - Чтобы просто вернуть чат к ИИ, не закрывая его совсем — используйте кнопку «Завершить» в веб‑панели

## «Позвать менеджера»
- При запросе:
  - Топик переименовывается в режим ожидания менеджера
  - В топик отправляется краткая сводка от ИИ по последнему сообщению клиента («Кратко: …»)
  - Уведомления в топике включаются

## Беззвучный режим
- До запроса менеджера все сообщения, дублируемые в топик, отправляются с `disable_notification=true`

## Сервисные сообщения форума
- Сообщения о создании, переименовании, закрытии/открытии топиков автоматически удаляются, чтобы не засорять ленту

## Команды менеджера внутри топика клиента

| Команда | Что делает |
|---|---|
| `/info` | Карточка клиента из Support API: баланс, подписки, ключи |
| `/summary` | AI-сводка текущего диалога — что за проблема, что уже пробовали |
| `/ai on` / `/ai off` | Включить/выключить ответы AI для этого чата — удобно, когда менеджер ведёт диалог сам |
| `/note <текст>` | Внутренняя заметка в историю чата — клиенту не отправляется, видна в топике и веб-панели |
| `/ban` / `/unban` | Заблокировать/разблокировать клиента — бот перестаёт отвечать и создавать уведомления |
| `/close` | Полностью закрыть чат — статус «закрыт», клиент уведомлён, тема становится зелёной |

Эти же команды работают и в личке с ботом, если указать ID чата: `/info 42`, `/ai off 42` и т.д.

## Кнопки при эскалации

Под сообщением о запросе менеджера (в топике и в личных уведомлениях) — две кнопки:

- **🙋 Взять в работу** — закрепляет чат за менеджером, уведомляет клиента о подключении. Если чат уже взят другим менеджером — бот сообщит кем
- Если менеджер отвечает клиенту в топике или личным сообщением, **не нажав** «Взять в работу» — чат закрепляется за ним автоматически по факту первого ответа, без лишнего клика
- **👤 Инфо** — та же карточка клиента, что и `/info`, но без набора команды

## Восстановление удалённых топиков
- Если топик был удалён, бот создаёт новый, обновляет привязки и повторяет операцию:
  - Создание/закреп карточки клиента
  - Переименование
  - Дублирование сообщений
